## 🚀 Local Development

> Ruby 3.2.x 버전 사용 권장

```bash
# Ruby 설치 후 버전 확인
ruby -v

# Bundler 설치
gem install bundler

# Bundler 버전 확인
bundle -v

# Ruby dependencies 설치
bundle install

# Node.js dependencies 설치
npm install && npm run build

# 로컬 서버 실행
bundle exec jekyll serve
```

서버 실행 후 `http://127.0.0.1:4000/` 에서 확인 가능

## 📝 Commit Convention

```
<emoji> <VERB> <object>
```

| Emoji | Code | 용도 |
|:-----:|------|-----|
| ✨ | `:sparkles:` | 새 포스트/콘텐츠 추가 |
| 📝 | `:memo:` | 기존 내용 수정/보완 |
| 🐛 | `:bug:` | 오타, 잘못된 내용 수정 |
| 🔧 | `:wrench:` | 설정/빌드 관련 수정 |
| 🎨 | `:art:` | 스타일/구조 개선 |
| 🗑️ | `:wastebasket:` | 삭제 |

**예시:**
```
✨ ADD Python metaclass post
📝 UPDATE GCN equation section
🐛 FIX typo in adjacency matrix
🔧 FIX jekyll config url
🎨 REFACTOR post structure
```
