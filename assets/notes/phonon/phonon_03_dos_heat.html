Thermal Properties of Materials · Lecture 4–5 Density of states, distribution, specific heat

3장. 모드를 세고, 채우고, 데우기

2장에서 결정의 진동 에너지는 E = Σ(nk + ½)ħωk 였습니다. 남은 질문은 두 가지입니다. 진동수 ω 근처에 모드가 몇 개 있는가(상태 밀도), 그리고 온도 T에서 각 모드에 포논이 몇 개 들어가는가(Bose-Einstein 분포). 둘을 곱하면 내부 에너지와 비열이 나옵니다.

각 단계는 직관 → 수식 → 이해 순서입니다. 수식은 다음 ▶(또는 키보드 →)으로 한 줄씩 넘기고, 그때마다 그 줄과 관련된 그림 칸이 주황 테두리로 강조됩니다. 현재 줄은 버튼 바로 아래에, 지난 줄은 그 밑에 쌓이고 누르면 그 줄로 돌아갑니다.

STEP 1 · Lecture 4 Density of states

상태 밀도: 진동수별로 모드 세기

직관

1장 STEP 5에서 허용된 k는 Δk = 2π/L 간격으로 고르게 찍혔습니다. 그 점들을 분산 곡선 위에서 오른쪽 ω축으로 옮겨 쌓아 봅니다.

해 보기: N을 키우고 다시 쌓기를 누르세요. 막대가 어디에 몰리나요? 곡선이 평평한 곳과 가파른 곳을 비교해 보세요.

수식
\(\Delta k = \dfrac{2\pi}{L} \;\Rightarrow\; D(k) = \dfrac{L}{2\pi}\)
k 공간에서는 상태가 균일하게 분포합니다 (단위 k당 개수).
2D 그림의 격자점 간격이 Δk입니다. k 공간에서는 점이 고르게 찍힙니다.
\(D(\omega)\,d\omega = 2\,D(k)\,dk\)
ω가 같은 +k와 −k 두 점을 함께 셉니다.
왼쪽 곡선 위의 점 하나하나가 같은 높이(같은 ω)의 오른쪽 막대로 옮겨집니다.
핵심 결과
\(D(\omega) = 2\,\dfrac{L}{2\pi}\,\dfrac{1}{|d\omega/dk|} = \dfrac{L}{\pi\,v_g}\)
군속도가 작은 곳(곡선이 평평한 곳)일수록 같은 dω 안에 k 점이 많이 들어갑니다.
곡선이 평평한 위쪽(ωmax 근처)으로 갈수록 막대가 길어집니다.
\(\text{1D 사슬: } D(\omega) = \dfrac{2N}{\pi}\dfrac{1}{\sqrt{\omega_{\max}^2 - \omega^2}}\)
vg = (a/2)√(ωmax² − ω²) 를 대입. ωmax에서 vg = 0이라 발산합니다 (van Hove 특이점).
파란 계단선이 이 식의 예측입니다. N을 키울수록 막대와 겹칩니다.
\(\text{Debye: } \omega = v_s k \text{ (모든 k에서)},\quad \int_0^{\omega_D} D\,d\omega = \text{모드 수}\)
분산을 직선으로 근사하고, 모드 수가 맞도록 최대 진동수 ωD에서 자릅니다.
회색 점선이 1D Debye입니다. 모든 높이에 같은 개수가 있고 ωD = π에서 끝납니다.
\(\text{3D Debye: } D(\omega) = \dfrac{3V\omega^2}{2\pi^2 v_s^3}\;\propto\;\omega^2\)
k 공간에서 반지름 k인 껍질의 점 개수 ∝ 4πk²dk. 편광 3개를 곱합니다. 아래 2D 그림에서는 고리 둘레 ∝ k입니다.
고리 안 점 개수가 k에 비례해 늘어납니다(2D). 3D 껍질이면 k²에 비례합니다.
\(\text{Einstein: } D(\omega) = 3N\,\delta(\omega - \omega_E)\)
모든 모드가 한 진동수. 평평한 광학 가지의 모형입니다.
STEP 3에서 Einstein 버튼을 누르면 δ 모양을 볼 수 있습니다.
이해

수식을 끝까지 넘기면 나타납니다.

상태 밀도는 분산 관계를 ω축으로 투영한 히스토그램입니다. 모드는 곡선이 평평한 곳, 즉 군속도가 느린 곳에 몰립니다. 3차원에서 k 공간 껍질이 넓어지는 효과 때문에 저주파에서는 D ∝ ω²가 됩니다.

확인 질문: 분산이 ω = vsk로 완전히 직선이면 1D의 D(ω)는 어떤 모양일까요?

vg = vs로 일정하니 D(ω) = L/(πvs), 평평한 상수입니다. 위 그림의 회색 점선(1D Debye)이 그것입니다. 실제 사슬은 vg가 줄어드는 고주파 쪽에 모드가 더 몰립니다.

왼쪽: 허용된 k (점)와 분산 곡선. 오른쪽: 같은 점들을 ω에 따라 쌓은 막대 = D(ω). 파란 곡선 = 이론 D(ω), 회색 점선 = 1D Debye

2D k 공간: 반지름 k ~ k+dk 고리 안의 점

고리 안의 점 개수 vs k (2D: ∝ k, 3D 껍질: ∝ k²)

STEP 2 · Lecture 4 Distribution functions

Bose-Einstein 분포: 온도가 포논 개수를 정한다

직관

2장 STEP 4에서는 포논을 손으로 넣었습니다. 이번에는 온도 T의 열원이 무작위로 넣고 뺍니다. 모드마다 포논 개수가 계속 바뀌고, 오래 평균하면 일정한 값(◆)으로 모입니다.

해 보기: T를 아주 낮게 내렸다가 올려 보세요. 어떤 모드가 먼저 깨어나나요? 주황 세로선 ħω = kBT 와 비교해 보세요.

수식
\(P(n) \propto e^{-E_n/k_BT},\quad E_n = \left(n+\tfrac12\right)\hbar\omega\)
온도 T와 열평형인 계가 에너지 E 상태에 있을 확률은 볼츠만 인자에 비례합니다. 오른쪽 아래 사다리의 막대 길이가 P(n)입니다.
사다리 막대 길이가 P(n)입니다. 위 칸일수록 지수적으로 짧아집니다.
\(x \equiv \dfrac{\hbar\omega}{k_BT} \;\Rightarrow\; P(n) = (1 - e^{-x})\,e^{-nx}\)
등비급수 Σe−nx = 1/(1−e−x)로 정규화.
T를 내리면 n = 0 막대만 길어집니다.
핵심 결과
\(\langle n\rangle = \displaystyle\sum_n n\,P(n) = \dfrac{1}{e^{\hbar\omega/k_BT} - 1} = f_{BE}(\omega, T)\)
포논은 개수가 보존되지 않으므로 화학 퍼텐셜 μ = 0 입니다 (Lecture 5).
◆(시간 평균)이 파란 곡선 fBE에 모입니다.
\(k_BT \gg \hbar\omega:\; f_{BE} \approx \dfrac{k_BT}{\hbar\omega} \;\Rightarrow\; \langle E\rangle \approx k_BT\)
고전 등분배. 모드마다 kBT씩.
주황 세로선 왼쪽 모드들은 fBE가 점선(고전)과 거의 겹칩니다.
\(k_BT \ll \hbar\omega:\; f_{BE} \approx e^{-\hbar\omega/k_BT} \to 0\)
계단 하나(ħω)가 열에너지보다 너무 높아서 모드가 '얼어' 있습니다.
주황 세로선 오른쪽 모드들에는 포논이 거의 없습니다.
\(f_{FD} = \dfrac{1}{e^{(E-\mu)/k_BT} + 1},\quad f_{MB} = e^{-(E-\mu)/k_BT}\)
전자(페르미온)는 한 상태에 하나만(+1). 점유가 작은 극한에서는 둘 다 Maxwell-Boltzmann이 됩니다.
BE(파랑), FD(보라), MB(점선)를 비교하세요.
이해

수식을 끝까지 넘기면 나타납니다.

온도는 "ħω가 kBT보다 작은 모드만 깨운다"는 기준선입니다. 그 아래 모드는 포논이 많고(고전적, ⟨E⟩ ≈ kBT), 위 모드는 거의 비어 있습니다. 저온에서 결정의 열적 성질은 깨어 있는 저주파 모드가 전부 결정합니다.

확인 질문: ħω = kBT인 모드의 평균 포논 수는?

x = 1이므로 ⟨n⟩ = 1/(e − 1) ≈ 0.58개. 고전 예측 kBT/ħω = 1과 이미 차이가 납니다.

모드별 포논 개수 (점 = 지금, ◆ = 시간 평균, 선 = fBE, 점선 = 고전 kBT/ħω). 열을 누르면 모드 선택

고른 모드의 사다리. 막대 길이 = P(n)

세 분포 비교 (x축 (E−μ)/kBT)

STEP 3 · Lecture 4 Internal energy

내부 에너지: 모드 수 × 포논 수 × 포논 에너지

직관

진동수 ω 근처의 에너지 = (그 근처 모드 개수) × (모드당 포논 수) × (포논 하나의 에너지). 오른쪽 세 그래프의 곱이 맨 아래 곡선이고, 그 넓이가 결정 전체의 진동 에너지 U입니다.

해 보기: 모형을 바꿔 가며 T를 내려 보세요. 넓이가 어느 진동수 쪽에서부터 줄어드나요?

수식
\(U = \displaystyle\int_0^{\infty} \hbar\omega\; D(\omega)\; f_{BE}(\omega, T)\; d\omega\)
영점 에너지 ½ħω는 온도에 무관한 상수라서 빼고 씁니다.
맨 아래 칠한 넓이가 U이고, 위 두 그래프를 곱한 것입니다.
\(\text{고온 } (k_BT \gg \hbar\omega_{\max}):\; \hbar\omega f_{BE} \approx k_BT \;\Rightarrow\; U \approx (\text{모드 수})\,k_BT = 3Nk_BT\)
T/Θ를 2 가까이 올리면 표시줄의 U/U고전이 1에 가까워집니다.
핵심 결과
\(\text{Debye: } U = 9Nk_BT\left(\dfrac{T}{\theta_D}\right)^3 \displaystyle\int_0^{\theta_D/T} \dfrac{x^3}{e^x - 1}\,dx,\quad \theta_D = \dfrac{\hbar\omega_D}{k_B}\)
D(ω) = 9Nω²/ωD³ 를 넣고 x = ħω/kBT로 바꿈.
3D Debye로 바꿨습니다. D ∝ ω²입니다.
\(\text{저온 } (T \ll \theta_D):\; \int_0^\infty \dfrac{x^3}{e^x-1}dx = \dfrac{\pi^4}{15} \;\Rightarrow\; U \propto T^4\)
깨어 있는 모드 수 ∝ T³ (D ∝ ω²), 각각 에너지 ~kBT.
T를 내리면 넓이가 저주파 쪽에만 남습니다.
\(\text{Einstein: } U = 3N\,\dfrac{\hbar\omega_E}{e^{\hbar\omega_E/k_BT} - 1}\)
모드가 모두 ωE에 있으니 적분이 한 항이 됩니다. 저온에서 지수적으로 사라집니다.
Einstein으로 바꿨습니다. 모든 모드가 한 진동수 ωE에 있습니다.
이해

수식을 끝까지 넘기면 나타납니다.

U는 "어떤 모드가 존재하는가"(D, 분산이 정함)와 "얼마나 채워졌는가"(fBE, 온도가 정함)의 곱입니다. 온도를 내리면 고주파 쪽부터 비워지므로, 저온 거동은 D(ω)의 저주파 모양(Debye ω², Einstein은 0)이 결정합니다.

확인 질문: 저온에서 Debye 모형과 Einstein 모형 중 U가 더 빨리 0으로 가는 쪽은?

Einstein. 가장 낮은 모드도 ħωE 높이에 있어서 e−θE/T로 꺼집니다. Debye 모형에는 아무리 낮은 T에서도 깨어 있는 저주파 음향 모드가 있어 T⁴로만 줄어듭니다.

위: D(ω)  가운데: fBE(ω,T)  아래: ħω·D·fBE (넓이 = U). 가로축 ħω/kBΘ

STEP 4 · Lecture 4–5 Specific heat

비열: 온도를 조금 올렸을 때 U가 얼마나 느나

직관

위쪽 줄의 동그라미 하나하나가 모드입니다. 밝기는 그 모드가 지금 열을 얼마나 받아들일 수 있는지(모드 비열)입니다. T를 올리면 저주파부터 차례로 켜지고, 다 켜지면 더는 밝아지지 않습니다.

해 보기: T를 Θ의 1/20 정도로 내려 보세요. Debye와 Einstein에서 켜진 모드가 어떻게 다른가요?

수식
\(C_V = \left(\dfrac{\partial U}{\partial T}\right)_V = \displaystyle\sum_{\text{modes}} c(x),\quad c(x) = k_B\dfrac{x^2 e^x}{(e^x - 1)^2},\; x = \dfrac{\hbar\omega}{k_BT}\)
모드 하나의 에너지 ħω fBE를 T로 미분. 위 동그라미의 밝기가 c(x)/kB입니다.
위 동그라미의 밝기가 c(x)/kB입니다.
\(x \to 0:\; c \to k_B \qquad x \gg 1:\; c \approx k_B x^2 e^{-x} \to 0\)
깨어 있는 모드는 kB씩, 얼어 있는 모드는 0을 기여합니다.
T를 내리면 오른쪽(고주파) 동그라미부터 꺼집니다.
\(\text{고온: } C_V \to 3Nk_B\)
Dulong-Petit 법칙. 모든 모드가 켜진 상태입니다.
C 그래프가 1(Dulong-Petit)에 다가갑니다.
핵심 결과
\(\text{Debye 저온: } C_V = \dfrac{12\pi^4}{5}Nk_B\left(\dfrac{T}{\theta_D}\right)^3 \;\propto\; T^3\)
아래 로그 그래프에서 기울기 3인 직선입니다.
로그 그래프에서 Debye 곡선이 기울기 3인 점선과 나란합니다.
\(\text{Einstein: } C_V = 3Nk_B\,\dfrac{x_E^2 e^{x_E}}{(e^{x_E}-1)^2} \;\propto\; e^{-\theta_E/T}\)
저온에서 실험(T³)보다 너무 빨리 떨어집니다. 이 차이가 Debye 모형이 나온 이유입니다 (Lecture 9 역사).
Einstein으로 바꿨습니다. 저온에서 Debye보다 훨씬 빨리 떨어집니다.
이해

수식을 끝까지 넘기면 나타납니다.

비열은 "지금 켜지는 중인 모드의 수"입니다. 고온에서는 모두 켜져 상수 3NkB, 저온에서는 켜지는 모드가 저주파 음향 모드뿐이라 D(ω) ∝ ω²에서 T³이 나옵니다. 이 C는 열전도도 κ = Σ C v² τ (Lecture 5)의 첫 번째 재료가 됩니다.

확인 질문: θD가 높은 물질(다이아몬드, θD ≈ 2200 K)은 상온에서 비열이 Dulong-Petit 값에 가까울까요?

아닙니다. T/θD ≈ 0.14라서 고주파 모드 상당수가 아직 얼어 있습니다. 3D Debye로 T/Θ = 0.14에 맞춰 보면 Dulong-Petit 값의 약 18%입니다. 실제 다이아몬드의 상온 비열은 약 6 J/mol·K로, 3R ≈ 25 J/mol·K의 1/4 정도입니다.

모드 (진동수 순서, 상태 밀도에 맞춰 뽑음). 밝기 = c(x)/kB

U(T) 와 접선. 기울기 = CV

CV / (모드 수 · kB)

로그-로그: 저온에서 Debye ∝ T³, Einstein은 지수적으로 사라짐

정리: 같은 틀, 다른 입자 (Lecture 5 요약)

분산 관계가 존재하는 상태를 정하고, 온도가 그 상태의 점유를 정합니다. 둘을 곱하면 U와 C가 나옵니다. 포논, 전자, 광자 모두 같은 순서를 따릅니다.

분산 관계상태 밀도분포 함수비열
포논음향 ω = vsk, 광학 ω ≈ ωEDebye ∝ ω², Einstein δ(ω−ωE), 모드 총 3N개fBE, μ = 0저온 ∝ T³, 고온 3NkB
전자E = ħ²k²/2m*3D ∝ √EfFD, 개수 고정 → μγT (EF 근처만 반응)
광자ω = ckω²/(π²c³), 편광 2개fBE, μ = 0U ∝ T⁴, C ∝ T³ (흑체 복사)

4장으로 → (Lecture 5–6). 지금까지는 평형 상태였습니다. 온도 기울기가 있으면 포논 분포가 fBE에서 조금 벗어나고(δf), 그 차이가 열을 나릅니다. Boltzmann 수송 방정식과 κ = Σ C v² τ 로 넘어갑니다.

온도는 Θ = ħωmax/kB 단위로 나타냈습니다 (Debye 모형에서는 Θ = θD). Einstein 모형은 ωE = 0.75 ωmax로 두었습니다. 괄호 안의 K 값은 Θ = 400 K라고 가정했을 때입니다. STEP 2의 무작위 포논 수는 확률 P(n)에서 뽑은 예시입니다.
