STEP 1 · Lecture 5

평형에서는 왜 열이 흐르지 않을까

직관

포논을 군속도 v로 날아다니는 입자(파동 묶음)로 봅니다. 오른쪽 막대 속 점 하나가 포논 하나이고, 가운데 점선을 지나갈 때마다 에너지를 옮깁니다.

해 보기: 오른쪽으로 건너간 에너지(→)와 왼쪽으로 건너간 에너지(←)를 몇 초 지켜보세요. 포논은 계속 움직이는데 알짜 흐름은 어떻게 되나요?

수식
\(f(\mathbf r, \mathbf k, t)\): 위치 r에서 파수 k인 상태의 점유도
포논 하나하나를 추적하는 대신, "r 근처에 k 상태 포논이 평균 몇 개 있나"만 다룹니다. 평형에서는 3장의 fBE입니다.
점들이 각자 다른 방향으로 날아다닙니다. 이 무리를 분포 f로 요약합니다.
\(f_0 = \dfrac{1}{e^{\hbar\omega/k_BT} - 1},\qquad \omega(\mathbf k) = \omega(-\mathbf k)\)
평형 분포는 진동수(에너지)에만 의존합니다. +k와 −k는 진동수가 같으니 점유도도 같습니다.
오른쪽으로 가는 포논(파랑)과 왼쪽으로 가는 포논(보라)의 수가 같습니다.
\(\mathbf q = \dfrac{1}{V}\displaystyle\sum_{\mathbf k} \hbar\omega_{\mathbf k}\,\htmlClass{tV}{\mathbf v_{\mathbf k}}\,f_{\mathbf k}\)
열유속 = (에너지) × (속도) × (개수)를 모든 상태에 대해 더한 것 (Lecture 5 "flux = quantity × velocity").
가운데 점선을 지나가는 에너지를 →, ← 따로 셉니다.
\(\htmlClass{tV}{\mathbf v_{-\mathbf k}} = -\htmlClass{tV}{\mathbf v_{\mathbf k}},\; f_0(-\mathbf k) = f_0(\mathbf k) \;\Rightarrow\; \mathbf q = 0\)
+k 항과 −k 항이 짝지어 상쇄됩니다. 포논이 아무리 빨리 움직여도 평형에서는 알짜 열 흐름이 0입니다.
알짜 흐름 막대가 0 근처에서만 흔들립니다.
\(f = f_0 + \delta f,\qquad \mathbf q = \dfrac{1}{V}\displaystyle\sum_{\mathbf k} \hbar\omega\,\htmlClass{tV}{\mathbf v}\,\delta f\)
열이 흐르려면 +k와 −k의 점유가 조금 달라야 합니다. f0 부분은 위에서 0이 되었으니, 열을 나르는 것은 오직 평형에서 벗어난 부분 δf입니다. δf를 구하는 식이 Boltzmann 수송 방정식(BTE)입니다.
다음 단계에서 막대 양 끝에 온도 차이를 걸어 δf를 만들어 봅니다.

열전도는 포논이 "있어서"가 아니라 오른쪽으로 가는 포논과 왼쪽으로 가는 포논이 "불균형해서" 생깁니다. 비열(3장)은 f0만으로 정해지지만, 열전도도는 δf가 필요한 비평형 성질입니다.

확인 질문: 평형인 결정에서 포논의 평균 속력은 0일까요?

아닙니다. 각 포논은 |vg|로 움직입니다. 0이 되는 것은 방향까지 더한 평균 속도이고, 그래서 알짜 열 흐름이 0입니다.

평형 상태의 포논 기체. 점 = 포논 (파랑 → 방향, 보라 ← 방향), 점선 = 에너지를 세는 단면

STEP 2 · Lecture 5–6

BTE: 표류와 산란의 경쟁

직관

이제 막대 왼쪽 끝은 뜨겁고 오른쪽 끝은 차갑습니다. 포논은 직선으로 날아가다가(표류) 평균 τ마다 한 번씩 산란되어, 그 자리 온도에 맞는 에너지와 무작위 방향을 새로 받습니다.

해 보기: 아래 그래프에서 오른쪽으로 가는 포논(파랑)과 왼쪽으로 가는 포논(보라)의 평균 에너지를 비교하세요. 그다음 τ를 줄였다 늘려 보세요. 두 선 사이 간격이 어떻게 변하나요?

수식
\(\dfrac{\partial f}{\partial t} + \htmlClass{tV}{\mathbf v}\cdot\nabla_{\mathbf r} f + \dfrac{\mathbf F}{\hbar}\cdot\nabla_{\mathbf k} f = \left(\dfrac{\partial f}{\partial t}\right)_{\text{coll}}\)
Boltzmann 수송 방정식. 왼쪽: 분포가 시간에 따라(1항), 공간 이동으로(2항), 외력으로 k가 바뀌어서(3항) 변하는 정도. 오른쪽: 산란이 분포를 바꾸는 정도.
점들이 날아가고(왼쪽 항) 가끔 반짝이며 산란됩니다(오른쪽 항).
\(\htmlClass{tV}{\mathbf v}\cdot\nabla_{\mathbf r} f\): 표류 (drift)
포논은 군속도로 이동하며 출발한 곳의 정보를 실어 나릅니다. 뜨거운 쪽에서 출발한 포논은 에너지가 큰 채로 차가운 쪽에 도착합니다. 포논에는 전기장 같은 외력이 없으므로 F = 0입니다.
몇몇 포논의 지나온 궤적을 선으로 남깁니다. 색은 지금 가진 에너지(빨강 = 뜨거움)입니다.
\(\left(\dfrac{\partial f}{\partial t}\right)_{\text{coll}} \approx -\dfrac{f - f_0}{\htmlClass{tTau}{\tau}}\)
완화 시간 근사(RTA). 평형에서 벗어난 만큼(f − f0)이 시간 상수 τ로 지수적으로 사라진다고 봅니다. 산란은 포논을 그 자리 온도의 평형 분포로 되돌려 놓습니다.
반짝이는 원이 산란 순간입니다. 산란 직후 포논의 색은 그 자리 배경 온도와 같아집니다.
\(\text{정상 상태, } \delta f \ll f_0:\quad \htmlClass{tV}{v_x}\,\dfrac{\partial f_0}{\partial x} = -\dfrac{\delta f}{\htmlClass{tTau}{\tau}}\)
시간에 따라 변하지 않고(∂f/∂t = 0), 벗어남이 작다고 보면 왼쪽의 f를 f0로 바꿔도 됩니다 (선형화). 여기서 f0는 그 자리 온도 T(x)의 평형 분포입니다.
배경 색이 T(x)입니다. 이 국소 평형이 f0입니다.
\(\delta f = -\htmlClass{tTau}{\tau}\,\htmlClass{tV}{v_x}\,\dfrac{\partial f_0}{\partial T}\,\htmlClass{tGrad}{\dfrac{dT}{dx}}\)
∂f0/∂x = (∂f0/∂T)(dT/dx). 부호를 보면 vx > 0(오른쪽으로 가는)이고 dT/dx < 0(오른쪽이 차가움)이면 δf > 0: 오른쪽으로 가는 포논이 평형보다 많습니다.
아래 그래프의 파랑(→)과 보라(←) 선 사이 간격이 δf입니다. 파랑이 늘 위에 있습니다.
\(\htmlClass{tTau}{\tau}\): 불균형이 얼마나 오래 사는가  ·  \(\htmlClass{tV}{v}\,\htmlClass{tGrad}{\nabla T}\): 기울기를 얼마나 세게 느끼는가  ·  \(\partial f_0/\partial T\): 점유가 온도에 얼마나 민감한가
오른쪽으로 가는 포논은 평균 거리 ℓ = vτ 만큼 왼쪽(더 뜨거운 곳)에서 마지막으로 평형을 맞췄습니다. 그래서 T(x − vτ)의 정보를 갖고 있습니다. δf는 그 거리만큼의 온도 차이입니다.
τ 슬라이더를 2배로 하면 두 선 사이 간격도 약 2배가 됩니다.

수식을 끝까지 넘기면 나타납니다.

온도 기울기가 직접 열을 흐르게 하는 것이 아닙니다. 기울기는 먼저 δf(방향별 불균형)를 만들고, 그 불균형의 크기는 "산란 없이 날아온 거리 vτ" 동안의 온도 차이로 정해집니다. 산란이 잦으면(τ 작음) 불균형이 금방 지워집니다.

확인 질문: 산란이 전혀 없으면(τ → ∞) δf는 무한대가 될까요?

식으로는 그렇지만 실제로는 막대 길이 L이 상한입니다. vτ가 L보다 길면 포논은 양 끝 열원에서 바로 날아오므로 "탄도(ballistic)" 수송이 됩니다 (Lecture 9). 오른쪽에서 τ를 최대로 올려 보세요.

뜨거운 왼쪽 끝 → 차가운 오른쪽 끝. 배경 = 국소 온도 T(x), 점 = 포논 (색 = 가진 에너지)

위치별 평균 에너지: 파랑 = 오른쪽으로 가는 포논, 보라 = 왼쪽으로 가는 포논, 회색 = T(x)

STEP 3 · Lecture 5–6

푸리에 법칙과 열전도도 κ

직관

STEP 2의 막대에서 실제로 흐른 열을 잽니다. 온도 차이를 두 배로 하면 열 흐름도 두 배가 되는지, τ를 바꾸면 비례 계수 κ가 어떻게 되는지 봅니다.

해 보기: ΔT를 바꿔서 측정점이 직선 위에 있는지 보세요. 그다음 τ를 여러 값으로 바꾸고 몇 초씩 기다리면 오른쪽 아래 그래프에 측정점이 쌓입니다. 어디서 직선(예측)과 어긋나기 시작하나요?

수식
\(q_x = \dfrac{1}{V}\displaystyle\sum_{\mathbf k} \hbar\omega\,\htmlClass{tV}{v_x}\,\delta f\)
STEP 1에서 본 대로 열을 나르는 것은 δf뿐입니다.
왼쪽 위 숫자: 막대를 지나는 열 흐름 q (측정).
\(q_x = -\left[\dfrac{1}{V}\displaystyle\sum_{\mathbf k} \hbar\omega\,\dfrac{\partial f_0}{\partial T}\,\htmlClass{tV}{v_x^2}\,\htmlClass{tTau}{\tau}\right]\htmlClass{tGrad}{\dfrac{dT}{dx}}\)
STEP 2의 δf를 대입. vx가 두 번 들어가서 vx²이 됩니다. 방향이 반대인 포논도 부호가 같아져 모두 같은 쪽으로 열을 나릅니다.
q가 ΔT에 비례하는지 왼쪽 위 그래프에서 확인하세요.
\(q = -\kappa\,\htmlClass{tGrad}{\nabla T}\) 와 비교 \(\Rightarrow\; \kappa = \dfrac{1}{V}\displaystyle\sum_{\mathbf k} \htmlClass{tC}{C_{\mathbf k}}\,\htmlClass{tV}{v_x^2}\,\htmlClass{tTau}{\tau_{\mathbf k}},\quad \htmlClass{tC}{C_{\mathbf k}} = \hbar\omega\dfrac{\partial f_0}{\partial T}\)
대괄호 속이 바로 푸리에 법칙의 κ입니다. Ck는 3장의 모드 비열 c(x)와 같은 양입니다.
오른쪽 위 막대: 측정한 κ와 C v² τ 예측.
\(\text{3D 등방: } \langle v_x^2\rangle = \tfrac13 v^2 \;\Rightarrow\; \kappa = \dfrac{1}{3V}\displaystyle\sum \htmlClass{tC}{C}\,\htmlClass{tV}{v^2}\,\htmlClass{tTau}{\tau} = \dfrac{1}{3V}\displaystyle\sum \htmlClass{tC}{C}\,\htmlClass{tV}{v}\,\ell,\quad \ell = \htmlClass{tV}{v}\htmlClass{tTau}{\tau}\)
3차원에서는 방향이 고르게 퍼져 있어 x 성분이 평균 1/3만 기여합니다. 이 그림의 막대는 1차원(방향이 ±x 둘뿐)이라 1/3이 없습니다: κ = n v² τ.
ℓ = vτ 가 표시줄에 나옵니다.
\(\ell \ll L\): 확산(diffusive), 푸리에 법칙 성립  /  \(\ell \gtrsim L\): 탄도(ballistic)
유도에서 "포논이 산란을 여러 번 겪으며 국소 평형을 유지한다"고 가정했습니다. ℓ이 막대 길이만큼 길어지면 그 가정이 깨지고, κ는 τ에 비례해 계속 커지지 못하고 막대 크기로 제한됩니다.
오른쪽 아래 그래프에서 τ가 클 때 측정점이 예측 직선 아래로 처집니다.

κ = (열을 얼마나 담나 C) × (얼마나 빨리 가나 v²) × (방향을 얼마나 오래 유지하나 τ). 열을 잘 전하려면 세 가지가 모두 커야 합니다 (Lecture 5). 푸리에 법칙은 BTE의 특수해이고, 평균자유행로가 시료보다 짧을 때만 성립합니다.

STEP 4 · Lecture 5–6, 9

모드별로 쌓은 κ: 누가 열을 나르나

직관

실제 결정에서는 모드마다 C, v, τ가 다릅니다. 1장의 원자 사슬 분산을 써서 세 값을 진동수별로 그리고, 셋을 곱한 것이 κ의 스펙트럼입니다.

해 보기: τ 모형을 바꿔 보세요. 고주파 포논의 τ가 짧아지면 열을 나르는 주역이 어느 쪽으로 옮겨가나요? 온도를 낮추면 어떤 모드가 빠지나요?

수식
\(\kappa = \dfrac13\displaystyle\sum_s\int \htmlClass{tC}{C(\omega)}\,\htmlClass{tV}{v^2(\omega)}\,\htmlClass{tTau}{\tau(\omega)}\,d\omega\)
모드 합을 진동수 적분으로 바꿈 (Lecture 6). s는 가지(LA, TA, …)입니다.
맨 아래 그래프의 칠한 넓이가 κ입니다.
\(\htmlClass{tC}{C(\omega)} = \hbar\omega\,\dfrac{\partial f_{BE}}{\partial T}\,D(\omega)\)
3장의 모드 비열 × 상태 밀도. 저온에서는 고주파 모드가 얼어서 0이 됩니다.
주황 곡선. T를 내리면 오른쪽(고주파)부터 줄어듭니다.
\(\htmlClass{tV}{v(\omega)} = d\omega/dk\)
1장의 군속도. 영역 경계 근처(ωmax)에서는 0이라 상태가 많아도(C 큼) 열을 못 나릅니다.
파랑 곡선. 오른쪽 끝에서 0으로 떨어집니다.
\(\htmlClass{tTau}{\tau(\omega)}\): 일정 / \(\propto \omega^{-2}\) (Umklapp 형태) / \(\propto \omega^{-4}\) (점결함, Rayleigh)
τ를 정하는 산란 과정은 다음 장(Lecture 7–8)의 주제입니다. 여기서는 흔한 진동수 의존성 세 가지만 미리 비교합니다.
보라 곡선(로그 축). 모형 버튼을 바꿔 보세요.
\(\kappa_{\text{acc}}(\ell) = \displaystyle\int_{\ell' < \ell} d\kappa\)
평균자유행로가 ℓ보다 짧은 포논이 κ에 얼마나 기여하는지 누적한 곡선. 시료 크기가 ℓ보다 작아지면 그보다 긴 ℓ의 기여가 잘려 나갑니다 (Lecture 9 나노 구조, 박막).

수식을 끝까지 넘기면 나타납니다.

열을 가장 많이 나르는 모드는 C, v, τ가 동시에 큰 곳, 보통 저·중주파 음향 포논입니다. 물질 사이를 비교하면 C는 Dulong-Petit 값으로 상한이 있고 v는 수 km/s 범위라 몇 배 차이에 그치지만, τ(ℓ)는 몇 자릿수씩 달라집니다. 그래서 κ를 이해하려면 결국 산란을 이해해야 합니다.

확인 질문: τ ∝ ω⁻⁴(점결함)일 때 고주파 포논의 기여는 왜 거의 사라질까요?
